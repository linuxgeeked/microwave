# Project Governance

The project is governed by the core appliance-controls team. Ownership, release authority, and security response authority remain with the project maintainers.

Contributions are reviewed under the project contribution policy. Maintainers perform periodic review of contributor access, organizational affiliations, funding relationships, and changes in project control.

The project does not accept undisclosed ownership, investment, or operational control from parties that could compromise the safety or independence of the firmware.
