# Security Policy

Security issues in the Microwave Control Firmware are handled through a private disclosure process. Reports are triaged by the security maintainer, assessed for exploitability and safety impact, and tracked through remediation.

Critical issues are targeted for remediation within seven days. High-severity issues are targeted within thirty days. Security fixes are included in the next available maintenance release.

The project performs automated source review and vulnerability checks as part of its continuous integration process. Changes affecting the heating chamber, door interlock, or power controls receive additional review.
